# Barbershop Backend — задание 1

Программа для записи клиентов в барбершоп на Python.

## Возможности

- Модели мастера, услуги и записи `Appoinment`.
- Функция `create_appointment()` возвращает объект `Appoinment` или `None`.
- Нельзя создать запись с пустыми полями либо несуществующим мастером или услугой.
- Записаться можно с **08:00 до 20:00 включительно**.
- Один мастер не может иметь две записи на одинаковое время.
- Два разных мастера могут принять клиентов одновременно.

## Запуск

Нужен Python 3.10 или новее. Сторонние библиотеки не требуются.

```bash
python main.py
```

Ожидаемый вывод:

```text
Список записей:
Иванова А.А. 10:00
Петрова А.А. 11:00
Количество записей: 2
```

## Тестирование

```bash
python -m unittest -v
```

Все данные хранятся в памяти программы: `masters`, `services`, `appointments`.

Для проверки некорректной записи на пустом списке вызов `create_appointment("", 1, 1, "12:00")` возвращает `None`, а `appointments` остаётся пустым.
